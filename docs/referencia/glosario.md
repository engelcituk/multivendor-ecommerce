# Glosario

| Término | Significado en Plazora |
| --- | --- |
| Administrador | Usuario interno autenticado mediante el guard `admin` |
| Cartera | Saldo operativo asociado a una tienda |
| Comisión | Parte del pedido retenida por la plataforma |
| KYC | Verificación de identidad o negocio del vendedor |
| Marketplace | Plataforma que reúne varias tiendas y clientes |
| Pedido por tienda | Orden generada para un vendedor a partir del carrito global |
| Producto digital | Artículo con archivo descargable y sin logística física |
| Producto físico | Artículo sujeto a stock y envío |
| Retiro | Solicitud del vendedor para recibir saldo de su cartera |
| Seeder | Clase que inserta datos iniciales desde Laravel |
| Snapshot SQL | Fotografía exportada de esquema y datos en un momento concreto |
| Store / tienda | Perfil comercial y propietario del catálogo vendido |
| Variante | Combinación vendible de atributos con precio o stock propio |
| Vendedor | Usuario con rol `vendor` y una tienda asociada |

## Convención de idioma

Los nombres técnicos existentes (`Store`, `Order`, tablas, relaciones y rutas) se conservan para no romper contratos de código. La interfaz y esta documentación usan equivalentes naturales en español.
